Deploy Course Online ke VPS Tanpa IP Publik

Panduan lengkap: install Webmin, LAMP Stack, upload project, dan akses dari internet via Cloudflare Tunnel.

Skenario: VPS kamu tidak punya IP publik, tetapi bisa diakses via SSH dari komputer lokal (IP privat / jaringan internal). Semua akses publik diarahkan melalui Cloudflare Tunnel.

3. Install Webmin di VPS

Konek ke VPS via SSH dari komputer lokal:

ssh root@IP_PRIVAT_VPS

Atau jika user biasa:

ssh user@IP_PRIVAT_VPS
1 Update package list 
sudo apt update && sudo apt upgrade -y
2 Install dependensi 
sudo apt install wget curl gnupg2 software-properties-common -y
3 Tambah repository Webmin 
curl -fsSL https://download.webmin.com/jcameron-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/webmin.gpg
echo "deb [signed-by=/usr/share/keyrings/webmin.gpg] https://download.webmin.com/download/repository sarge contrib" | sudo tee /etc/apt/sources.list.d/webmin.list
4 Install Webmin 
sudo apt update
sudo apt install webmin -y
5 Cek status Webmin 
sudo systemctl status webmin

Pastikan status active (running).

Selesai install. Sekarang buka terminal baru di komputer lokal untuk akses Webmin via SSH tunnel.

4. Akses Webmin via SSH Tunnel

Karena VPS tidak punya IP publik, Webmin diakses lewat SSH tunnel. Buka terminal baru di komputer lokal kamu (selain yang sedang SSH ke VPS):

1 Buat SSH tunnel untuk Webmin 
ssh -L 10000:localhost:10000 user@IP_PRIVAT_VPS

Ganti user dan IP_PRIVAT_VPS dengan data VPS kamu.

Biarkan terminal ini tetap terbuka (jangan di-close).

2 Buka Webmin di browser

Buka browser di komputer lokal, akses:

https://localhost:10000

Browser akan menampilkan peringatan self-signed SSL. Klik Advanced > Proceed to localhost (unsafe).

3 Login Webmin

Gunakan username dan password user root atau user sudo VPS kamu.

Penting: SSH tunnel harus tetap berjalan selama kamu mengakses Webmin. Jika koneksi terputus, ulangi perintah ssh -L 10000:localhost:10000 user@IP_PRIVAT_VPS.
Windows: Bisa juga pakai PowerShell: 
ssh -L 10000:localhost:10000 user@IP_PRIVAT_VPS -N
Flag -N membuat terminal hanya diam (tidak membuka shell), tunnel tetap jalan di background.

5. Install LAMP Stack via Webmin

1 Buka Command Shell

Di Webmin, buka Tools > Command Shell.

2 Install Apache 
sudo apt install apache2 -y

Setelah selesai, buka Others > Apache Webserver untuk memastikan module Apache sudah muncul.

3 Install MySQL 
sudo apt install mysql-server -y

Jalankan security script:

sudo mysql_secure_installation

Atur password root MySQL. Module MySQL akan muncul di Servers > MySQL Database Server.

4 Install PHP 
sudo apt install php php-mysql php-mbstring php-xml php-curl libapache2-mod-php php-zip php-gd php-intl -y

Cek versi:

php -v
5 Restart Apache 
sudo systemctl restart apache2
Info: Module Apache, MySQL, dan PHP sekarang akan muncul di menu Servers Webmin.

8. Konfigurasi Project via Webmin

Gunakan Tools > File Manager. Klik kanan file > Edit (atau double-klik).

8a. Konfigurasi Database

Edit /var/www/html/course_online/application/config/database.php:

$db['default'] = array(
    'dsn'     => '',
    'hostname' => 'localhost',
    'username' => 'course_user',
    'password' => 'GantiDenganPasswordKuat123!',
    'database' => 'db_course_online',
    'dbdriver' => 'mysqli',
    'dbprefix' => '',
    'pconnect' => FALSE,
    'db_debug' => (ENVIRONMENT !== 'production'),
    'cache_on' => FALSE,
    'cachedir' => '',
    'char_set' => 'utf8',
    'dbcollat' => 'utf8_general_ci',
    'swap_pre' => '',
    'encrypt' => FALSE,
    'compress' => FALSE,
    'stricton' => FALSE,
    'failover' => array(),
    'save_queries' => TRUE
);

Ganti password dengan password user MySQL yang dibuat di langkah 6.

8b. Konfigurasi Base URL

Edit /var/www/html/course_online/application/config/config.php:

$config['base_url'] = 'https://course.kamu.com/';

Ganti course.kamu.com dengan domain/subdomain yang akan kamu pakai di Cloudflare Tunnel.

8c. Set Index Page (untuk URL Clean)

Di file config.php yang sama:

$config['index_page'] = '';

Klik Save.

10. Konfigurasi Apache via Webmin

1 Aktifkan mod_rewrite

Via Tools > Command Shell:

sudo a2enmod rewrite
sudo systemctl restart apache2
2 Edit VirtualHost Apache

Via File Manager Webmin, buka /etc/apache2/sites-available/000-default.conf.

Edit menjadi:

<VirtualHost *:80>
    ServerAdmin webmaster@localhost
    DocumentRoot /var/www/html/course_online
    SetEnv CI_ENV production

    <Directory /var/www/html/course_online>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
</VirtualHost>

Klik Save.

3 Restart Apache 
sudo systemctl restart apache2

Atau via Webmin: buka Others > Apache Webserver > klik tombol Restart Apache.

11. Production Settings

Via File Manager, edit /var/www/html/course_online/index.php:

define('ENVIRONMENT', isset($_SERVER['CI_ENV']) ? $_SERVER['CI_ENV'] : 'production');

Variabel CI_ENV=production sudah diset di VirtualHost (langkah 10), jadi CodeIgniter otomatis pakai mode production.

12. Cloudflare Tunnel

VPS tanpa IP publik tetap bisa diakses dari internet. Cloudflare Tunnel bekerja dengan membuat koneksi keluar (outbound) dari VPS ke Cloudflare.

1 Install cloudflared

Via Tools > Command Shell:

curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o /tmp/cloudflared.deb
sudo dpkg -i /tmp/cloudflared.deb
2 Login ke Cloudflare 
cloudflared tunnel login

Perintah ini akan menampilkan URL. Copy URL tersebut, buka di browser komputer lokal, dan login ke akun Cloudflare.

Pilih domain yang akan dipakai. File sertifikat akan terdownload otomatis di VPS.

3 Buat Tunnel 
cloudflared tunnel create course-online

Catat Tunnel ID yang muncul di output.

4 Buat file konfigurasi tunnel

Via File Manager Webmin, buka /root/.cloudflared/ (aktifkan tampilan file tersembunyi di Webmin: Webmin > Webmin Configuration > File Manager Options > Show hidden files: Yes).

Buat file baru config.yml, isi dengan:

tunnel: course-online
credentials-file: /root/.cloudflared/<TUNNEL_ID>.json

ingress:
  - hostname: course.kamu.com
    service: http://localhost:80
  - service: http_status:404

Ganti <TUNNEL_ID> dengan ID dari langkah 3, dan course.kamu.com dengan domain kamu.

5 Routing DNS Cloudflare 
cloudflared tunnel route dns course-online course.kamu.com

Otomatis menambah DNS record CNAME di Cloudflare.

6 Install tunnel sebagai service (auto-start) 
sudo cloudflared service install
7 Start & Enable tunnel 
sudo systemctl start cloudflared
sudo systemctl enable cloudflared
sudo systemctl status cloudflared

Pastikan status active (running).

Selesai! Buka https://course.kamu.com di browser. SSL aktif otomatis dari Cloudflare. Aplikasi Course Online seharusnya sudah bisa diakses dari internet.

13. Firewall via Webmin

Karena akses ke VPS hanya lewat SSH dan Cloudflare Tunnel (outbound), firewall cukup longgar.

1 Buka Linux Firewall

Webmin > Networking > Linux Firewall.

2 Pastikan port 22 dan 10000 terbuka
PortKeteranganStatus
22SSHBuka
10000WebminBuka (dari jaringan lokal saja)
80Apache (untuk tunnel)Buka

Port 80 harus terbuka agar Cloudflare Tunnel bisa terhubung ke Apache di VPS.

Catatan: Port 10000 (Webmin) tidak perlu diakses dari publik karena sudah diakses via SSH tunnel. Port 80 tidak perlu diakses langsung dari browser publik karena semua traffic masuk lewat Cloudflare Tunnel.

14. Verifikasi & Troubleshooting

Verifikasi

  1. Buka https://course.kamu.com → halaman Course Online tampil
  2. Cek halaman login, register, halaman course
  3. Pastikan SSL aktif (icon gembok di address bar)
  4. Coba upload gambar dari admin panel → pastikan tersimpan di folder uploads/

Troubleshooting

MasalahSolusi
Error 500 / blank page Cek log: Others > Apache Webserver > View Error Log. Juga cek /var/www/html/course_online/application/logs/ via File Manager.
Database connection error Verifikasi username, password, nama DB di database.php. Via Command Shell: mysql -u course_user -p -e "SHOW DATABASES;"
Upload file tidak tersimpan Pastikan folder uploads/ punya permission 777 dan owner www-data.
404 halaman selain homepage Pastikan mod_rewrite aktif, AllowOverride All di VirtualHost, dan config['index_page'] = ''.
Cloudflare Tunnel tidak connect Cek log: sudo journalctl -u cloudflared -f. Pastikan config.yml benar.
Webmin tidak bisa diakses Pastikan SSH tunnel -L 10000:localhost:10000 berjalan. Cek status: sudo systemctl status webmin.
Cloudflare Tunnel: Connection Refused Pastikan Apache berjalan: sudo systemctl status apache2. Tunnel mengarah ke localhost:80.
