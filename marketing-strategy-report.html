Executive Summary

Overview

REBAS COURSE adalah platform LMS dengan fondasi produk yang kuat — 25 tabel database, 16 controller, fitur lengkap (quiz, assignment, sertifikat, forum, mentoring). Dari sisi marketing, platform ini memiliki keunggulan kompetitif: fully bilingual, hero configurable via admin, testimonial & review system, 7 social media terintegrasi, dan sertifikat yang bisa di-share.

Namun, terdapat 3 masalah kritis yang membuat semua upaya marketing menjadi buta dan tidak terukur:

🔴 Zero Analytics

Tidak ada GA4, Facebook Pixel, atau tracking apapun. Tidak bisa mengukur traffic, konversi, atau ROI marketing.

🔴 No Email Capture

Tidak ada newsletter, mailing list, atau lead magnet. Leads hilang setelah meninggalkan website.

🔴 No SEO Foundation

Tidak ada sitemap, OG tags, Schema.org, atau blog. Google tidak bisa mengindeks konten secara optimal.

✅ Strengths

  • Hero & homepage fully configurable
  • Review & rating (social proof)
  • Sertifikat bisa di-share
  • Bilingual (ID/EN)
  • Forum komunitas

❌ Weaknesses

  • Zero analytics/tracking
  • No email marketing
  • Pricing hanya cosmetic
  • No blog/content marketing
  • No landing pages (about, contact, FAQ)

🌱 Opportunities

  • Market kursus online Indonesia tumbuh 25% YoY
  • Content type "article" sudah ada di DB
  • 7 social media terintegrasi
  • Affiliate marketing potensi tinggi

⚠️ Threats

  • Kompetitor: Ruangguru, Coursera, Udemy
  • No recurring revenue model
  • Zero brand awareness di search engine

🔴 Pilar 1: Analytics Foundation

Minggu 1 — Prasyarat
📊

Tanpa Data, Marketing Buta

Estimasi: 2 hari • Prioritas: #1

Ini adalah fondasi dari semua strategi marketing. Tanpa analytics, tidak ada cara untuk mengetahui: dari mana traffic berasal, halaman mana yang dikonversi, campaign mana yang efektif, atau di mana letak bottleneck di funnel.

A. Google Analytics 4 (GA4)

Implementasi

<!-- Di header.php, sebelum </head> --> <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script> <script> window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', ''); </script>

Setting Baru

  • analytics_ga4_id — GA4 Measurement ID
  • analytics_fb_pixel — Facebook Pixel ID
  • analytics_gtm_id — Google Tag Manager ID (opsional)

B. Facebook Pixel + Event Tracking

// assets/js/analytics.js — Universal Event Tracker window.REBAS = window.REBAS || {}; REBAS.track = function(eventName, params) { // GA4 Event if (typeof gtag !== 'undefined') { gtag('event', eventName, params); } // Facebook Pixel Event if (typeof fbq !== 'undefined') { fbq('trackCustom', eventName, params); } }; // Track key events: // PageView → otomatis // ViewContent → halaman course // AddToWishlist → klik bookmark // InitiateCheckout → klik beli // Purchase → transaksi sukses // CompleteRegistration → register sukses // CompleteLesson → lesson selesai // Share → klik share

Flow UTM

  1. JS capture UTM params dari URL → simpan di session/cookie
  2. Saat register sukses, simpan ke tabel user_sources
  3. Admin bisa lihat source traffic di halaman user detail
  4. Korelasi source dengan enrollment & revenue

🟡 Pilar 3: Conversion & Retention

Minggu 4-8 — Monetisasi
💰

Visitor → Customer → Loyal Student

Estimasi: 4 minggu • Impact: Revenue

Pilar ini berfokus pada mengubah visitor menjadi paying customer dan menjaga mereka tetap engaged. Tactics mencakup optimasi landing page, email drip, discount engine, dan social proof.

A. Conversion Rate Optimization (CRO)

Social Proof Bar

Floating bar di bagian bawah layar:

🎉 1.234 siswa telah mendaftar bulan ini • Bergabung sekarang!

Angka real-time dari query count enrollments bulan ini.

Exit-Intent Popup

Modal muncul saat mouse meninggalkan window:

  • Email capture: "Dapatkan akses gratis ke 3 course"
  • Discount: "Jangan lewatkan diskon 20% pertama Anda!"
  • Integrasi dengan Mailgun untuk auto-responder

B. Email Drip Campaigns

4 automated sequences — setelah email notification system terpasang:

SequenceTriggerEmailsTujuan
👋 WelcomeRegisterD+0, D+1, D+3Aktivasi & eksplorasi fitur
📚 OnboardingEnroll courseD+0, D+2, D+5, D+10Course completion rate
🔄 Re-engagementNo login > 14 hariD+14, D+21, D+30Bring back dormant users
🛒 Abandoned CartPending payment > 1 jamH+1, H+24Konversi pembayaran
Email Marketing ROI: Rata-rata $42 untuk setiap $1 yang dihabiskan (Litmus 2025). Untuk platform LMS, email drip dapat meningkatkan course completion rate hingga 30%.
